# Career Clarity & Mentoring Platform (Bangladesh)

## Problem
Bangladeshi students/graduates (18–25) are confused about career direction. Counselor currently runs intake, assessment, recommendations and follow-ups via forms, spreadsheets and WhatsApp — no structure, no tracking.

## Target user
- **Mentee:** university/college student or recent graduate, unsure of career path.
- **Counselor (builder):** reviews assessments, writes recommendations, builds roadmaps, tracks sessions.

## Core objects
Mentee, Assessment Question, Assessment Response, Career Profile, Career Direction, Roadmap (90-day), Roadmap Task, Counselor Recommendation, Mentoring Session.

## MVP (v1) — must-haves
- [ ] Structured career assessment (~40 questions: interests, strengths, skills, values, preferences)
- [ ] Rule-based scoring → Career Profile (5 dimensions + values + skills gap)
- [ ] 3–5 recommended Career Directions with fit score + Bangladesh job-market rationale
- [ ] Auto-generated 90-day Roadmap with weekly tasks; mentee marks tasks done
- [ ] Counselor console: review any mentee's profile/roadmap, add recommendations, log sessions
- [ ] Progress status visible to both mentee and counselor
- [ ] Demo mode: main screens viewable without login, seeded demo mentees

## Non-goals (v1)
No mobile app, no AI chatbot, no job board/employer marketplace, no payments, no video calls, no psychometric platform, no automated career "diagnosis", no community features.

## Success criteria (one end-to-end scenario)
> A student completes the assessment unaided, sees a clear Career Profile, 3–5 ranked directions with local-context rationale, and a 90-day plan; marks first task done; counselor opens the console, reviews the profile, posts a recommendation and logs a session. All of this persists in the database and survives refresh.

10 pilot users complete this flow without assistance within a week.
